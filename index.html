Источники данных

Рыночные цены и сведения о Гунах загружаются из общественного API TarkovStammtisch, который использует данные сообщества и Tarkov.dev.

API: api.tarkov-stammtisch.de · режим PvE · данные не являются официальной телеметрией игровых серверов.

Если источник недоступен, приложение покажет ошибку, а не выдуманные значения.

Обновление

Цены, согласно документации API, обновляются примерно каждые 5–10 минут. Данные о Гунах — по последнему сообщению сообщества; частота синхронизации около минуты.
