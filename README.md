# TARKOV ASSISTANT v2 — расширенный PWA-прототип

## Установка обновления в GitHub Pages
1. Открой репозиторий Tarkov-Assistant на GitHub.
2. Открой папку корня репозитория и выбери Add file → Upload files.
3. Загрузи index.html, manifest.json и sw.js из этой папки, согласись заменить существующие файлы.
4. Нажми Commit changes.
5. Открой опубликованный сайт в Chrome. Если видна старая версия, обнови страницу или очисти кэш сайта.

## Модули
- Goons Tracker: последнее community-сообщение через сторонний API; не является телеметрией игры.
- Flea Market PvE: поиск цен через API, избранное и целевые цены.
- Карты: выбор локации, переход на интерактивную карту Mapgenie и локальные заметки.
- Квесты: пользовательский чек-лист заданий.
- Loot: личный список нужных предметов и поиск через рынок.
- Досье боссов: краткая справочная информация.
- Loadout: чек-лист подготовки к рейду и сохранение плана.
- Price alerts: избранное и запрос разрешения на уведомления. Фоновая проверка пока не реализована.
- Голосовые команды: SpeechRecognition в браузерах, которые его поддерживают; также доступен ввод текста.
- Заметки хранятся локально в браузере.

## Ограничения
Это PWA-прототип, а не нативный APK. Для установки нужен HTTPS-хостинг. Сторонний API может менять схему или быть временно недоступен. Цены и отчёты могут быть неполными или устаревшими. Автоматическая фоновая проверка цен, полноценная база квестов, графики истории цен и синхронизация между устройствами пока не реализованы.
