# TARKOV ASSISTANT — Android-ready PWA prototype

## Запуск на Android
1. Распакуй архив и размести папку на HTTPS-хостинге (например, GitHub Pages).
2. Открой опубликованный адрес в Chrome на Android.
3. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран».

Локально можно открыть index.html для просмотра, но установка PWA и сетевые запросы требуют HTTPS/поддерживаемого браузера.

## Что уже работает
- PvE Goons Tracker: запрашивает последнее community-сообщение и показывает возраст отчёта.
- PvE Flea Market: ищет предметы, показывает минимальную/среднюю/максимальную цену и время обновления.
- Заметки сохраняются локально на устройстве.
- Мобильный интерфейс в тактическом стиле.

## Ограничения
- Это PWA-прототип, не подписанный APK и не готовый нативный Android-проект.
- Goons Tracker показывает последнее сообщение сообщества, а не состояние игровых серверов и не гарантирует текущую локацию.
- Цены зависят от доступности стороннего API и могут быть неполными/устаревшими.
- Из списка рынка намеренно скрываются категории оружия, боеприпасов и оружейных модификаций.
- Для полноценной публикации/нативного APK понадобятся отдельная сборка, тестирование и проверка актуальных условий API.
